# روضة المسلم — مشروع Android قابل للبناء عبر GitHub Actions

## محتويات المشروع
- `app/src/main/assets/index.html`: صفحة التطبيق الأصلية التي أرسلتها.
- `app/src/main/java/...`: تطبيق Android WebView وجسر مزامنة مواعيد الصلاة مع AlarmManager.
- `.github/workflows/build-apk.yml`: يبني APK تلقائيًا عند Push أو يدويًا من GitHub Actions.

## رفع المشروع إلى GitHub
1. فك ضغط ملف ZIP على الكمبيوتر.
2. أنشئ Repository جديدًا على GitHub.
3. ارفع **محتويات** المجلد إلى المستودع (اجعل `app` و`build.gradle` و`.github` في الجذر).
4. افتح تبويب **Actions** ووافق على تفعيل GitHub Actions إذا طُلب.
5. اختر **Build Android APK** ثم **Run workflow**، أو انتظر انتهاء البناء بعد رفع الملفات.
6. افتح عملية البناء الناجحة، ثم من **Artifacts** نزّل `RawdatAlMuslim-debug-apk`.
7. فك ضغط الـ Artifact وثبّت `app-debug.apk` على هاتف Android.

## ملفات يجب أن تضيفها بنفسك
الحزمة لا تحتوي على ملفاتك الصوتية أو المصحف:
- ضع `standard1-quran.pdf` داخل `app/src/main/assets/` بجوار `index.html`.
- ضع ملفات MP3 التالية داخل `app/src/main/assets/` وبالأسماء المطابقة تمامًا لما في HTML:
  - `اذان الفجر.mp3`
  - `اذان عبدالباسط.mp3`
  - `اذان محمد رفعت.mp3`
  - `اذان ناصر القطامي.mp3`
  - `اذان مشاري بن راشد.mp3`
  - `اذان محمود خليل الحصري.mp3`
  - `اذان محمد علي البنا.mp3`
  - `اذان مصطفي اسماعيل.mp3`

بعد إضافة الملفات، ارفعها إلى GitHub ثم أعد تشغيل workflow. لا تضع الملفات داخل مجلد `audio`؛ يجب أن تكون بجوار `index.html`.

## ملاحظات مهمة قبل الاعتماد
- أول مرة افتح التطبيق واسمح بإشعارات Android. فعّل إذن **Alarms & reminders / المنبهات والتذكيرات** من إعدادات التطبيق إذا طلبه Android؛ بعض الأجهزة تحتاج ذلك للسماح بالتنبيه الدقيق.
- هذا المشروع يربط إعدادات الصلاة الموجودة في HTML بجدولة Android الأصلية، ويعيد جدولة المواقيت بعد إعادة تشغيل الهاتف. اختبره بموعد تجريبي بعد دقيقتين قبل الاعتماد عليه.
- قيود النظام والشركة المصنّعة ووضع توفير البطارية قد تؤثر على تشغيل الصوت في الخلفية. لا تعتمد عليه وحده كمنبه موثوق قبل اختباره على هاتفك.
- الصوت يعمل من ملفات محلية فقط إذا أضفت ملفات MP3 بالأسماء الصحيحة. تشغيل التلاوة والإذاعة يحتاج اتصال إنترنت.
- عرض PDF داخل WebView يعتمد على دعم عارض PDF في الجهاز؛ إذا لم يظهر المصحف داخل التطبيق، يلزم إضافة عارض PDF مدمج لاحقًا.
- النسخة الناتجة Debug APK للتجربة والتثبيت اليدوي، وليست نسخة Release موقعة للنشر على المتجر.
